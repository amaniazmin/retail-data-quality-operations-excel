# Retail Data Quality & Operations Control

## Project Overview

An Excel-based data operations workflow designed to validate, investigate, reconcile, and prepare retail transaction data before downstream processing.

---

## Business Workflow

Retailer Input File

↓

Raw Data Validation

↓

Exception Detection

↓

Exception Management

↓

Clean Output Generation

↓

Operational Dashboard

↓

Downstream Delivery

---

## Dataset

- Source: UCI Machine Learning Repository
- Dataset: Online Retail II
- Transactions analyzed: 9,999

---

## Validation Rules

- Customer ID validation
- Cancellation detection
- Quantity validation
- Price validation
- Duplicate detection

---

## Exception Management

Transactions were classified into:

- PASS
- REVIEW
- REJECT

---

## Results

| KPI | Value |
| --- | ---: |
| Total Records | 9,999 |
| PASS | 6,705 |
| REVIEW | 489 |
| REJECT | 2,805 |
